# 沙雕塔受压连锁塌陷试验台（PlayCanvas）

一个纯前端的结构失稳仿真：对一座由 **4 根粗颗粒沙柱 + 6 根木质横梁 + 承压石板** 组成的沙雕塔
施加塔顶载荷，观察沙柱压短变粗、压屈弯曲、局部塌陷，以及塌陷后重量沿横梁向邻柱转嫁的**连锁反应**。

## 运行

无需构建，任意静态服务器即可（引擎已本地内置于 `vendor/`，不依赖外网 CDN）：

```bash
# 任选其一
npx serve .
python -m http.server 8080
```

然后浏览器打开对应地址。也可直接双击 `index.html`（部分浏览器对本地 file:// 的纹理有限制，推荐用服务器）。

### 自动化冒烟测试

`test/smoke.js` 通过 CDP 驱动本机 Edge（SwiftShader 软渲染）无头加载页面，
校验渲染无报错、3D 拾取、遥测面板、临界预设与连锁塌陷时序，并输出截图到 `test/shot*.png`：

```bash
node test/smoke.js
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 拖动「塔顶载荷」滑块 | 连续加压/卸载，载荷缓动跟随，运行流畅 |
| 点击沙柱（或右侧列表） | 查看该柱轴力、承压比、压缩量、弯曲挠度、横梁传力 |
| `⚡ 一键加载临界预设 F*`（快捷键 C） | 载荷卡在首柱塌陷临界边缘（1.02·F* + 微小扰动），触发从一处起裂的连锁塌陷 |
| `▶ 缓慢加压至临界`（R） | 9 秒准静态爬升到临界边缘 |
| `🎥 镜头绕塔预演`（O） | 相机绕塔两圈的电影式观察 |
| 鼠标拖拽 / 滚轮 / 单指 / 双指 | 旋转视角、缩放、触摸拾取 |
| `↺ 复位沙塔`（0） | 全部柱体恢复初始状态 |

## 物理模型

截面形状按需求做了简化（圆形截面），但**连锁传力严格守恒**。

- **非线性轴向弹簧沙柱**：弹性段 `N = k·Δh`；越过峰值 `Nᵤ` 进入峰后应变软化
  （剪胀、承载力跌落至残余摩擦强度）；压缩到位移阈值触发**局部塌陷**。
- **横梁竖向剪力耦合**：柱顶由 6 根横梁（4 边梁 + 2 对角梁）连成框架，
  柱 `i` 受到的横梁合力 `Fb_i = kb·Σⱼ(y_j − y_i)`。某柱软化下沉时，横梁对它向上托举、
  对邻柱向下加压——把它承担的重量转嫁给邻柱。所有横梁力在节点上成对出现，**总和恒为 0**。
- **动力学积分**：半隐式欧拉 + 阻尼，每帧 4 个子步。塌陷因此沿横梁网络逐柱蔓延，
  实测时序约 C1→C2→C3→C4，相邻柱间隔 ~0.2 s。
- **临界载荷 F***：启动时以强阻尼准静态爬升离线搜索首柱塌陷的临界总载荷，
  作为滑块刻度与一键预设的基准。
- **视觉变形**：每根柱子是一张连续自定义网格（26 高度环 × 20 径向段），
  顶点按承压比驱动半正弦压屈挠曲、泊松压短变粗、塌陷带局部缩颈堆胀；
  砂粒材质用程序化粗颗粒漫反射 + 法线贴图表现。
