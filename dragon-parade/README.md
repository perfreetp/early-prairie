# 元宵龙灯巡街 · Babylon.js 三维确定性仿真

单文件三维场景：青石板街道、两侧摊位与看灯人群，龙头沿预置路径巡街，龙身按固定间距跟随、
转弯甩出平滑弧线、近摊位侧身避让（间距先拉长再弹性收拢），并含一个"龙头卡巷、队伍逐节停住"
的边界情况。支持时间轴任意回拖，龙头位置、每节龙身姿态与避让偏移都精确复原。

## 运行

方式一（推荐，避免本地文件协议限制）：

```bash
python -m http.server 8731
# 浏览器打开 http://127.0.0.1:8731/index.html
```

方式二：直接用浏览器打开 `index.html`（需联网从 cdnjs 加载 Babylon.js 7.0）。

鼠标左键旋转、右键平移、滚轮缩放；左侧面板切换路线、拖时间轴、调播放速度、开关镜头跟随。

## 三条预置路线（切换后龙灯从头走一遍）

| 路线 | 形态 | 避让点 | 同街口避让幅度 |
|---|---|---|---|
| 一 · 直街 | 长直青石板街 | 2 个 | 0.70 m |
| 二 · 拐弯 | 两处 R=6m 直角圆角弯 | 2 个（在直道段） | 1.25 m（比直街大） |
| 三 · 卡巷 | 先正常避让，再进净宽 1.45m 巷口 | 1 个 + 卡停点 s=30 | 龙头宽 1.38m，余量仅 0.07m |

## 联动规则（谁先变、谁跟着变）

1. **龙头先变**：沿路径弧长匀速前进，进入避让区先产生侧身偏移并向摊位一侧倾斜。
2. **龙身跟着变**：每节龙身只在**龙头的历史轨迹**（含偏移后的世界位置）上按弧长滞后
   `N × 间距` 取样，所以后一节的避让开始/回正都比前一节晚，延迟沿队伍逐节传播。
3. **转弯不硬折**：龙身取的是龙头走过的轨迹，弯道处自然沿平滑弧线甩出。
4. **先拉长再收拢**：避让时目标间距 = 固定间距 ×（1 + 前一节拉伸量），偏移回正后弹簧逐节收拢。
5. **卡巷停车波**：龙头先冻结在巷口，追赶弹簧把停车逐节向后传（实测龙头→龙尾约 4.3s 停稳）。

## 架构：仿真与渲染分离

`index.html` 内 `/*SIM_CORE_START*/ … /*SIM_CORE_END*/` 之间是**纯仿真内核**，不依赖
Babylon/DOM，所有状态只由 `(routeId, t)` 决定，固定步长 `1/120s` 推进：

- 路径：折线 **R=6m 圆角** → **向心 Catmull-Rom**（α=0.5，不打环不尖点）→ 控制点
  **1.4m 等距重采样**（消除长直段+密弧点导致的 S 形抖动）→ 弧长表重采样。
- 龙头历史轨迹按 0.2m 弧长存"锚点+偏移+侧倾"，龙身在其上插值跟随。
- 时间轴回拖 = 从 t=0 用固定步长确定性重放到目标时刻（`SIM.seek`），因此逐帧可复原。

渲染层（Babylon）只读 `SIM.snapshot()` 摆网格，自身不保存任何动画状态。
